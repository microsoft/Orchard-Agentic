Project page Paper ↗

Shared infrastructure

Orchard Env is a thin, Kubernetes-native environment service for isolated, multi-turn agent interaction. It remains independent from any one trainer, harness, or task domain.

View Orchard Env on GitHub ↗
  • Sandbox lifecycle Isolated environments with resource limits, timeouts, and network policy.
  • Multi-turn execution Commands, files, patches, and persistent state throughout an agent trajectory.
  • Harness agnostic The same primitives across different trainers, harnesses, and inference backends.
  • Built for scale Concurrent Kubernetes sandboxes with a low-latency in-pod execution path.
